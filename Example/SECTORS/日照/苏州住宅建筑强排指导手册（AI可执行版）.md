## 1. 总则与输入数据

### 1.1 总体假设

- 地势平坦，层高统一为 **3.1m**（每层）。
- 日照计算高度为 **室内地坪以上0.9m**。
- 日照标准：**大寒日2小时**（有效时段8:00~16:00，真太阳时，累计不超过两段，每段≥30分钟）。
- 建筑物模型为**长方体体块**，忽略屋顶、女儿墙、保温层、阳台、室内外高差等细部。
- 所有山墙默认**两侧均有窗**。
- 不考虑住宅垂直布置。
- 日照以幢为单位，住宅可以独幢、双拼，双拼不可高低拼，不可多拼。

### 1.2 输入数据清单

AI必须接收以下参数：

- **用地轮廓线**：多边形（平面坐标，1985国家高程基准）。
- **建筑控制线**：退让后的可建设范围线。
- **周边建筑**：每个邻建的外轮廓（平面）、**高度（m）**、属性（是否住宅）。
- **目标户型轮廓**：新建住宅的标准平面（面宽、进深）。
- **地块指标**：容积率上限、建筑高度上限（m 或 层数）。

## 2. 建筑朝向与贴线规则（技巧部分）

### 2.1 判断南北边线

- 南北边线：地块边界中与正北方向夹角 ≤45° 的线段。
- 计算该边线的方位角 `α`（0°~45°，取锐角）。

### 2.2 南北边线处理

#### 情况 A：`α < 15°`

- **第一排（紧贴该边线）**：建筑朝向 **平行于边线**。
- **内部建筑**：
  - 若地块南北向总排数 `N ≤ 4`：所有建筑朝向均平行于该边线。
  - 若 `N > 4`：仅第一排平行于边线，其余（第2排及以后）朝向 **正南北**（0°）。

#### 情况 B：`α ≥ 15°`

- **第一排（紧贴边线）**：建筑朝向 **正南北**，但需 **贴线**（建筑进深方向紧贴建筑控制线，沿边线方向可分段错动，不必排成直线）。
- **内部建筑**：朝向 **正南北**，无特殊贴线要求。

### 2.3 东西边线处理

- 无论东西边线角度如何，**建筑朝向不改变**（按上一条规则确定），仅要求 **贴线**（山墙侧或南北侧紧贴控制线），但仍需满足最小间距。

------

## 3. 建筑分类与间距控制方法

### 3.1 计算目标

- 用地南侧建筑为遮挡建筑。
- 用地东西侧建筑需要加入日照模拟计算。若是住宅不考虑日照间距，需考虑山墙最小间距。
- 用地北侧建筑，若是住宅，需考虑日照系数间距、最小间距、日照模拟计算。

### 3.1 分类界限

- **低层/多层**：对应层数 ≤ 9层。不考虑高度，只考虑实际住宅层数。
- **高层**：≥10层。

### 3.2 低层/多层住宅间距控制（三个参数取最大值）

三个参数：

1. **日照系数法**（公式见下文）
2. **最小间距表**（文件A 表3.2.8.1，平行/垂直布置）
3. **日照软件模拟**（大寒日2h，最终验证）

**最终间距 = max(日照系数间距, 表列最小间距, 日照模拟达标间距)**

### 3.3 高层住宅间距控制（两个参数取最大值）

两个参数：

1. **固定最小间距 40m**
2. **日照软件模拟**（大寒日2h）

**最终间距 = max(40m, 日照模拟达标间距)**

## 4. 日照系数法详细计算

### 4.1 计算高度 `H_calc`

- 当建筑地面层为住宅时，从室内地坪以上0.9m起算至遮挡建筑顶部。
- 公式：`H_calc = (层数 × 3.1) - 0.9` （单位：米）

### 4.2 基本日照间距

- 苏州日照系数 `i = 1.30`（大寒日2小时，文件A 表3.2.3）
- `L_sun_basic = i × H_calc = 1.30 × (层数×3.1 - 0.9)`

### 4.3 方位折减（仅用于低/多层，且当建筑非正南北时）

- 查文件A 表3.2.3.4，依据建筑方位角 `β`（与正南的夹角）：
  - `0° < β ≤ 15°`：折减系数 = 1.0
  - `15° < β ≤ 60°`：折减系数 = 0.9
- 最终 `L_sun = L_sun_basic × 折减系数`

### 4.4 高层建筑不采用方位折减，仅用日照软件模拟

## 6. 日照软件模拟要求

### 6.1 计算范围

- 拟建高层 ≤100m：向北 **150m扇形** 阴影区。
- 拟建高层 >100m：向北 **240m扇形** 阴影区。
- 同时考虑南侧150/240m内的遮挡建筑（文件B 3.1）。

### 6.2 计算方法

- 采用 **沿线分析**：基准线取建筑南侧整个外墙面（高度0.9m线），采样点间距 ≤1m。
- 不考虑自遮挡比例限制。
- 不进行窗户建模，不区分阳台。

### 6.3 建模参数

- 经纬度：姑苏/相城/吴中（不含东山）为北纬31°19′，东经120°37′。
- 采样时间间隔：1分钟。
- 太阳扫掠角 ≥15°。
- 时间安全阈值5分钟。

## 7. 特殊情况处理

### 7.1 间距不足时的措施

当计算所得“最终间距”大于实际可用间距时，可依次尝试：

1. **调整布局**（错位、降低面宽、分段布置）。
2. **降低南侧建筑高度**（减层）。减层后需重新分类（高层→多层），并重新计算。
3. **架空北侧建筑**。架空抬高日照计算基准面高度（0.9m变为 `架空高度+0.9m`），可降低日照系数计算高度和改善模拟结果，但无法改变建筑最小间距。

### 7.2 减层策略

若南侧建筑减层后为多层及以下，则具体减层数由解不等式：
`1.30 × (层数×3.1 - 0.9) ≤ 实际间距` 且 `层数 ≤ 9`。
例：间距35m → 层数 ≤ 8.97 → 取8层。

## 8. 强排总体流程

1. **读入输入数据**，建模简化体块。
2. **确定地块南北边线**，按朝向与贴线规则设置每栋建筑的朝向及第一排贴线属性。
3. **生成初始排布**（从南向北逐排，考虑贴线及间距）。
   - 排布原则：北高南低，西高东低，南北高度可以一样，但不能北低南高，东西同一排高度一般一样。
   - 18层以下可以用同一个户型，19层以上，可以用同一个户型，不可混用。
4. **对每对相邻建筑（新建-新建，新建-周边）**：
   - 判断新建建筑的类型（高层/低多层）。
   - 计算所需间距。
   - 若实际布置间距不足，返回调整（错位、减层、缩小面宽或增大间距）。
5. **南北向初排日照间距技巧**：
   - 遮挡建筑为低层、多层，考虑顺序为：最小间距、日照系数。一般满足日照系数，模拟计算也满足2h。
   - 遮挡建筑为高层，先统一以40m布置，若地块南北剩余不足一排，多余尺寸优先给到高层间距。
6. **进行日照软件模拟**（可调用外部计算引擎），验证所有被遮挡住宅的南墙面（0.9m高）满足大寒日2h。
7. **校核容积率与高度**：总建筑面积 ≤ 容积率×用地面积；每栋高度 ≤ 限高。
8. **输出最终布局**：每栋建筑的坐标、面宽、进深、层数、朝向，以及间距计算书和日照结论。
